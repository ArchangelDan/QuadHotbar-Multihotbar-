# QuadHotbar

> More room for building. The familiar hotbar, expanded.

QuadHotbar adds up to four switchable hotbars, giving players quick access to up to 36 inventory slots. It is designed for comfortable building, creative work, and any situation where the standard nine-slot hotbar is not enough.

## Supported versions

QuadHotbar supports:

- Minecraft 1.21.1 with NeoForge
- Minecraft 1.20.1 with Forge

For multiplayer, QuadHotbar must be installed on both the client and the server.
